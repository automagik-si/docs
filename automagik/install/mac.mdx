## Before you start

- A Mac with **Apple silicon** (M1 or newer).
- **macOS 13** or newer.
- An internet connection for the download and the accounts you connect.

This guide uses Desktop **v3.129.0**, the newest stable release checked on 12 November 2026.
The disk image is `Automagik-Mac.dmg`
(also released as `Automagik-3.129.0-mac-arm64.dmg`).

## Install

1. [Download the Mac disk image][download].
2. Open `Automagik-Mac.dmg` from your Downloads folder.
3. Drag **Automagik** onto **Applications** in the window that opens.
4. Open **Automagik** from Applications. If macOS asks whether to open an app downloaded
   from the internet, choose **Open**.
5. Once the welcome appears, eject the disk image in Finder. You can delete the download.

The welcome confirms the app has opened. Continue with
[your first connections](/automagik/getting-started#after-desktop-opens).

## Updates and existing installs

Use **Automagik → Check for Updates…** to check manually. When a downloaded update is
ready, choose **Restart now**, or **Later** to keep working.

An older app called **Omni** can update into Automagik and keep its data. If you already
have that app, update it instead of installing a second copy beside it.

If the disk image will not open, check that your Mac has Apple silicon and meets the
macOS requirement. Download the file again if the first download was interrupted.

For Code mode, [install Herdr and the Automagik pack](/automagik/install/herdr) separately.
